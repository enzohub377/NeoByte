🚀 NeoByte

NeoByte é um projeto de site institucional com foco em tecnologia, inovação e futuro digital.
O objetivo é apresentar a identidade, filosofia, serviços e diferenciais de uma empresa fictícia (ou conceitual) de tecnologia, com visual moderno e linguagem criativa.

“Na NeoByte, inovamos hoje para transformar o amanhã.”

📌 Visão Geral

O site da NeoByte foi desenvolvido utilizando HTML5 e CSS3, seguindo uma proposta visual futurista e conceitual.
Ele apresenta:

Identidade da marca

Propósito e filosofia

Serviços inovadores

Estilo de atendimento diferenciado

Cultura interna criativa

🛠️ Tecnologias Utilizadas

HTML5 — Estrutura do site

CSS3 — Estilização e identidade visual

Design responsivo (baseado em viewport)
